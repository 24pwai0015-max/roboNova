# Assignment

## Task

### RoboNova Basic Hardware Architecture

Design RoboNova's basic hardware architecture by including the following components:

* Environment
* Sensors
* Controller (Arduino Uno & Raspberry Pi)
* Decision Making
* Actuators
* Mechanical Body
* Power Supply
* Communication Module

### Workflow

```
Environment
      ↓
Sensors
      ↓
Controller
      ↓
Decision Making
      ↓
Actuators
      ↓
Mechanical Body
      ↓
Action
```

### Components Used

#### Sensors

* Camera
* Microphone
* Ultrasonic Sensor
* Touch Sensor

#### Controller

* Arduino Uno (Hardware Control)
* Raspberry Pi (AI, Computer Vision, Voice Processing)

#### Actuators

* Servo Motors
* DC Motors
* Stepper Motors

#### Power Supply

* Li-ion Battery

#### Communication Module

* Wi-Fi
* Bluetooth
* USB

# Reflection

While designing RoboNova's architecture, I understood that a robot is not just a machine but a complete system in which every component has a specific responsibility. Sensors collect information from the environment and send it to the controllers. Arduino Uno controls the hardware, while Raspberry Pi performs intelligent tasks such as AI processing and computer vision. The controllers make decisions, and the actuators convert those decisions into physical movement. The mechanical body carries out the actions, while the power supply provides energy to all electronic components. Communication modules enable RoboNova to connect with other devices when needed. This activity helped me understand how all the components work together to create an intelligent robot.
