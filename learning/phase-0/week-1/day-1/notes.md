# What is Robotics?

Robotics is a multidisciplinary field that combines:

- Mechanical Engineering
- Electronics
- Computer Science
- Artificial Intelligence
- Control Systems

The goal of robotics is to design, build, and program intelligent machines that can interact with the world.

---

# What is a Robot?

A robot is a machine capable of:

1. Sensing its environment.
2. Processing information.
3. Acting based on decisions.

This process is known as:

Sense → Think → Act

---

# Five Essential Components

- Sensors
- Controller (Brain)
- Actuators
- Power Supply
- Mechanical Body

---

# Sense → Think → Act

Sense:
Collect information using sensors.

Think:
Process the information and decide what to do.

Act:
Perform an action using actuators.
